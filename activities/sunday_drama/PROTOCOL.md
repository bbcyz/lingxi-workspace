# 周日追剧盛宴 1.0.1

平台格式为 `1`，标识 `sunday-drama`，页面 `/sunday-drama`，API `/api/sunday-drama/`。源码、页面和资源均在本目录，可通过平台管理导出、导入或更新，无须为活动内容升级整个平台。

## 已接通的流程

- 使用平台共享账号的有效 QWHD APP 身份查询活动、个性化任务、剩余机会、视频进度、邀请进度和奖品记录。
- 完成浏览签到活动、周三充值日、余量查询、本月账单、爱奇艺热播短剧、全球通礼遇、网龄成长计划和关注优质作者，共 8 个每周任务。余量和账单同时核对实际业务数据；短剧实际解码播放官方指定内容至少 30 秒。
- 全球通礼遇先查询本号会员资料，核对号码与官方全球通等级，再访问已认证的礼遇页面。网龄任务先查询本号真实成长等级，仅 V5 可提交；不符合资格时显示原因，不用单纯访问入口代替资格验证。
- 作者任务使用官方推荐池中的“中国移动”（作者 ID 10）。已有关注直接复用；未关注时真实提交一次关注，回读关注成功后才回传任务，再核对活动任务和机会。不会取消关注后重复关注刷任务。
- 每日实际播放官方视频 300 秒，周一至周六每天一次、周日两次。CMLIVE 接口返回的 `scanTime=5` 不能代替真实页面规定的 300 秒。
- 周日提交抽奖并回读剩余次数和中奖记录。手动点击使用一次机会；自动任务逐次使用当周剩余机会，未中奖不显示为中奖。
- 获取官方邀请链接、口令和海报，链接与口令可一键复制。邀请奖励在本地选择并再次确认，每月只能领取一档。
- 每日自动任务覆盖全部有效共享账号。默认每天北京时间 00:05 开始，周日 00:10 开始抽奖；晚启动或恢复登录后查询官方进度并补做。可在本地页面关闭、调整时间或排除 5 分钟视频。

会员部分可在本地点击“查询现有订购”，从官方已订业务中筛选爱奇艺、随心看相关产品。该结果只代表现有订购，不代表符合活动赠送权益资格。当前活动配置未提供可核验的会员办理和权益领取入口，不能据此选择相似商品代办、推断领取成功或提交付费订单；页面保留明确的未接通说明。

签到模块按当前官方公告暂停，预计 12 月恢复；当前不会提交活动签到。恢复后的接口与奖励须再次核对。

## 关键接口与提交边界

路径均相对于 `https://wx.10086.cn/qwhdhub`。请求必须使用当前活动的 Referer 和对应账号 Cookie。

| 接口 | 用途与边界 |
| --- | --- |
| `GET /diyActivity/info/1126082530` | 读取配置和规则。 |
| `GET /diyTask/list/{抽奖组件ID}` | 个性化任务；参数是关联抽奖组件，不是任务列表组件。 |
| `POST /diyLottery/period/remain/{抽奖组件ID}` | 读取剩余机会，虽然使用 POST，实际为只读。 |
| `GET /diyTask/startBrowse/{本人任务ID}` | **会改变任务或机会状态**；先保存提交意图，再实际访问官方返回的目标。 |
| `POST /diyTask/receive` | 对官方 `WAIT_RECEIVE` 状态领取机会，随后核对 `DONE`。 |
| `GET /diyLottery/lotterySafely/{组件ID}` | **抽奖提交**，不是只读 GET。 |
| `GET /diyLottery/queryWinRecord?withStatus=true` | 官方中奖记录；中奖时间字段为 `winAt`。 |
| `GET /api/diyVideoDayRedesign/task/queryDiyVideoTask` | 每日及每周视频进度。 |
| CMLIVE `GET /advert/lottery/getFiveMinuteTaskInfo` | 获取当前实际视频任务，沿用已有 CMLIVE 身份。 |
| CMLIVE `GET /advert/lottery/fiveMinuteTaskFinish` | **视频完成提交**；只在真实播放达到 300 秒后发送。 |
| CMLIVE `POST /user/author/queryAuthorInfo` | 读取官方作者及本人真实关注状态。 |
| CMLIVE `GET /advert/lottery/getFollowAuthorTask` | 获取本号、当前周作者任务参数；加密保存并复用。 |
| CMLIVE `POST /user/customer/following` | **真实关注提交**，仅使用 `status=1`；已关注不重复发送。 |
| CMLIVE `GET /advert/lottery/followAuthorTaskFinish` | **作者任务完成提交**，仅在真实关注已确认后发送，再查询活动 `DONE`。 |
| `POST /diyLottery/querySeckillCoupons`、`POST /diyTeam/progress` | 邀请场次与实际人数；后者须带官方当前 `activityId`。 |
| `POST /diyTeam/getKeyword`、`POST /diyTeam/invite/qrcode` | 生成邀请素材，按官方场次复用，不由页面轮询反复生成。 |
| `POST /diyLottery/lotterySafely` | 领取所选邀请档位，须带场次和官方奖品编码。 |

普通 H5 浏览任务可能在 `startBrowse` 时就被记账。本实现仍实际访问目标、满足时长并回读，不重复调用仅供原生拉端分支使用的 `finishBrowse`。已验证余量、账单的旧入口会跳转至 `wx.10086.cn/cmcc-service/app-pages/main/marginQuery` 和 `phoneBills`。

定向资格使用目标业务的只读接口：网龄 COC `POST /activities/growth/query`（渠道 `P00000006088`）；全球通 `POST /2016tyjf/xhmqqthy/member/func/queryVipLevel.do`（`sspId=75900`）。全球通缺失身份时，用户主动执行可通过 QWHD `GET /user/getYDRZToken?targetSourceId=001191` 与礼遇 SSO 建立一次身份。有效身份直接访问实际承接页，不再次消耗 SSO 票据。

## 会话、隔离与失败处理

- 依赖平台 1.10.0 的共享账号、`features.checkin`、信息查询、网龄、星动日会话和凭据缓存运行库；复用 QWHD、CMLIVE、COC 与全球通兼容身份。没有浏览器、ADB、合作 APP 或手机实时取值依赖。
- 全球通礼遇按本号使用 `global-tone:privileges` 缓存，遵从官方 `access_token` 到期信息；可借用有效星动日身份。认证与星动日共用账号锁，避免并发重复建立身份。向星动日复用已认证身份时保留原始建立时间，最多 2 小时，不覆盖有效短信会话、验证码流程或正在提交的业务。
- 后台礼遇任务只复用现有有效身份；缺失时等待每日星动日准备得到的身份，或由用户主动执行按需认证。不会为了后台礼遇任务额外触发星动日登录、签到、参数获取或强制续期。资格查询也不调用星动日已完成账号的签到、领取记录。
- 已通过对照确认，有效身份无需重新 APP SSO；某些活动查询在首次正确进入页面前会失败。活动入口上下文按账号与真实 QWHD Cookie 指纹保存，不以共享凭据版本号或程序重启为由重建。周日按本周记录实际进入一次活动，后续机会以官方查询为准。
- 活动配置、记录、未知提交意图、视频任务令牌和邀请素材使用平台加密存储。状态 API 不返回 Cookie、视频令牌或入口指纹；导出源码 ZIP 不含账号与运行数据。
- 新内置活动与导入版使用同一个 `activity-plugin:sunday-drama` 命名空间，升级测试覆盖内置版更新为下一补丁版后保留状态；活动包版本变化不会新建账号或丢弃有效会话。
- 主动打开、重新选择账号或刷新会立即排入独立读取线程池，不等待视频工作线程；页面自动刷新只读取本地记录。
- 提交意图先落盘。结果不确定时先查官方状态，不自动重放；后台至多安排两次间隔 5 分钟的只读结果核对。已确认的任务、已消耗的抽奖机会不会重复提交。
- 不符合资格、限流或需要验证时停止当日自动资格尝试，不影响同号其他可做任务。资格暂未完整返回不视为不合格，临时失败间隔 5 分钟、当天最多 3 次。等待身份只在真实有效身份改变后接续，不以共享凭据版本变化重试；用户主动“重新核对”可再次查询。恢复有效登录后接续身份失败任务，不自动发送短信。已有的其他活动定时频率、并发和轮次不变。
- 作者关注结果不确定时，先查询真实关注状态；只有确认已关注，才可继续尚未发送的完成回传。回传结果不确定时只查询活动进度，不自动重放回传。
- 播放阶段不占用共享登录提交锁；停止活动时终止本活动拥有的解码进程，不再回传完成记录。
